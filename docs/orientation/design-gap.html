Implemented Proposed

Thesis

Living Knowledge currently contains proposed contracts and lineage design, and no application implementation. Every component, LK00 through LK10, is Proposed. Nothing in the repository runs, so none is Implemented.

The pilot boundary and accountable owners are still being decided in BRO-5. Target nodes cannot be scoped into implementation tickets until that decision lands. See the README and the component map.
